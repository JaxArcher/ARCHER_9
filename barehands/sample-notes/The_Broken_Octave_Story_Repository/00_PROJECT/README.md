# The Broken Octave / Iron Trials — Structured Story Repository

**Status:** ACTIVE / DEVELOPING
**Last reconciled:** 2026-09-15
**Component type:** Repository index
**Source basis:** Story Bible v13 + newer project decisions through 2026-09-15


This repository separates the story into granular Markdown files so individual pieces can be retrieved, edited, compared, and recombined without treating every brainstorm as canon.

## Repository map
- `00_PROJECT/` — status dashboard, governance, open questions, continuity log
- `01_NARRATIVE/` — premise, plot, themes, structure, timeline
- `02_SUBPLOTS/` — one file per major thread
- `03_CHARACTERS/` — one file per established or placeholder character
- `04_LOCATIONS/` — settings and geography
- `05_WORLD/` — politics, society, economy, technology
- `06_MAGIC/` — current rules plus legacy mechanics needing reconciliation
- `07_CHAPTERS/` — Book One and Book Two, one file per chapter
- `08_FACTIONS/` — institutions and organized groups
- `09_LORE/` — historical/metaphysical lore
- `10_REFERENCE/` — indexes, glossary, relationship and setup/payoff maps

## Working philosophy
Every file should answer:
1. What is established?
2. What job does it do in the narrative?
3. What does it depend on?
4. What remains unresolved or contradictory?
