ARCHER Startup Commands:
.\.venv\Scripts\python.exe -m archer
.\.venv\Scripts\python.exe -m archer.web_main
.\.venv\Scripts\archer-web.exe
Barehand for local http://127.0.0.1:8200/app
python -m archer.web_main runs the module directly with whatever Python/venv you invoke it with. Works immediately, no install step.
archer-web is a shorter console-script shortcut (defined in pyproject.toml) that does the exact same thing. It only exists if ARCHER's been installed as a package into your environment (pip install -e . or similar) — since your .venv already has ARCHER installed that way, archer-web should just work as a shorthand.
